# 📖 Guia do Usuário - Elevare Editorial AI

## Bem-vindo!

Este guia irá ajudá-lo a aproveitar ao máximo a plataforma Elevare Editorial AI para gerar artigos automatizados e otimizados para SEO.

## 🎯 Começando

### Primeiro Acesso

1. **Página Inicial**: Ao acessar, você verá a landing page com informações sobre a plataforma
2. **Clique em "Começar Agora"** para entrar no dashboard
3. Você terá **180 créditos** disponíveis para gerar artigos

## 📊 Dashboard

O Dashboard é sua central de controle, mostrando:

- **Estatísticas**: Artigos gerados, taxa de conversão, tráfego orgânico, tempo economizado
- **Artigos Recentes**: Últimos artigos publicados ou agendados
- **Ações Rápidas**: Botões para gerar artigo, ver relatórios e configurar SEO

### Navegação

Use o menu superior para acessar:
- **Dashboard**: Visão geral e métricas
- **Hub Central**: Gerenciar todos os artigos
- **Gerador**: Criar novos artigos com IA
- **Autopilot**: Configurar publicação automática
- **YouTube**: Converter vídeos em artigos
- **Web Stories**: Criar stories visuais
- **Exemplos**: Ver artigos de sucesso

## ✍️ Gerando Artigos

### Passo a Passo

1. **Acesse o Gerador** (menu "Gerador")
2. **Preencha os campos**:
   - **Palavra-chave Principal**: Ex: "Criomodelagem", "Harmonização Facial"
   - **Tipo de Artigo**: Escolha entre:
     - Procedimento
     - Autoridade Clínica
     - Educativo
     - Gestão Estética
     - Tendência de Beleza
     - Resenha de Produto
   - **Tom do Artigo**: Profissional, Casual, Técnico ou Conversacional
   - **Tamanho**: Curto (~800), Médio (~1500) ou Longo (~2500 palavras)

3. **Clique em "Gerar Artigo"**
4. **Aguarde**: A IA levará cerca de 10-30 segundos
5. **Revise o Preview**: O artigo aparecerá no painel direito
6. **Copie ou Edite**: Use o botão "Copiar" para usar o conteúdo

### Dicas para Melhores Resultados

✅ **Use palavras-chave específicas**: "Criomodelagem em São Paulo" é melhor que só "Estética"

✅ **Escolha o tipo correto**: Cada tipo tem estrutura otimizada para seu propósito

✅ **Revise o conteúdo**: Sempre adicione seu toque pessoal e verifique a precisão

✅ **Ajuste o tom**: Para clínicas de luxo, use "Profissional"; para blogs informais, use "Conversacional"

## 🗂️ Hub Central

O Hub Central é onde você gerencia todos os seus artigos.

### Funcionalidades

- **Busca**: Procure artigos por palavra-chave ou tópico
- **Filtros**: Filtre por status (Pendente, Gerado, Publicado, etc.)
- **Tabela Completa**: Veja todos os detalhes:
  - Tópico do artigo
  - Palavra-chave
  - Tipo
  - Status atual
  - SEO Score (0-100)
  - Canais de publicação (B=Blog, P=Pinterest, L=LinkedIn, A=Audio)
- **Ações**: Visualizar, Editar ou Excluir artigos

### Status dos Artigos

- **Pendente** ⏱️: Aguardando geração
- **Gerado** 📝: Artigo criado, aguardando revisão
- **Otimizado** ✨: SEO otimizado
- **Agendado** 📅: Programado para publicação
- **Publicado** ✅: Já está no ar
- **Erro** ⚠️: Problema na geração/publicação

### SEO Score

O score de 0-100 indica a qualidade SEO:
- **90-100**: Excelente ⭐⭐⭐⭐⭐
- **70-89**: Bom ⭐⭐⭐⭐
- **50-69**: Regular ⭐⭐⭐
- **0-49**: Precisa melhorar ⭐⭐

## ⚡ Autopilot - Publicação Automática

Configure a publicação automática para economizar tempo.

### Configurações de Publicação

1. **Publicação Automática**
   - ✅ Ativado: Publica sem revisão
   - ❌ Desativado: Requer aprovação manual

2. **Frequência de Publicação**
   - Diária: 1 post por dia
   - Semanal: Escolha quantos posts por semana (1-7)
   - Personalizada: Defina horários específicos

3. **Posts por Semana**
   - Defina de 1 a 7 posts
   - Recomendado: 3 posts/semana para consistência

### Plataformas Conectadas

#### WordPress
- **Status**: Conectado ✅
- **URL**: https://clinica-exemplo.com
- **Ação**: Publica automaticamente via REST API

#### Wix
- **Status**: Disponível para conexão
- **Ação**: Clique em "Conectar" e faça login

#### Google Sheets
- **Status**: Sincronizado ✅
- **Uso**: Registra todos os posts para controle

#### n8n Automation
- **Status**: Webhook ativo ✅
- **Uso**: Automação avançada e integrações customizadas

### Como Conectar WordPress

1. Em seu site WordPress, instale o plugin "Application Passwords"
2. Vá em Usuários > Seu Perfil
3. Role até "Application Passwords"
4. Crie uma nova senha com nome "Elevare AI"
5. Copie a senha gerada
6. No Autopilot, clique em "Conectar" no card WordPress
7. Cole a URL do seu site e a senha
8. Salve as configurações

## 🎬 Conversor YouTube

Transforme vídeos em artigos escritos.

### Como Usar

1. **Copie a URL** do vídeo YouTube
2. **Cole no campo** do Conversor
3. **Clique em "Converter em Artigo"**
4. **Aguarde** o processamento (pode levar 1-2 minutos)
5. **Edite e Baixe** o artigo gerado

### Quando Usar

✅ Você tem um canal YouTube e quer conteúdo para o blog

✅ Encontrou um vídeo relevante do nicho

✅ Quer criar conteúdo baseado em palestras/webinars

## 🆘 Problemas Comuns

### "Erro ao gerar artigo"
**Solução**: Verifique se a API Key do Gemini está configurada corretamente no `.env.local`

### "SEO Score muito baixo"
**Solução**: Adicione mais palavras-chave, aumente o tamanho do artigo, melhore a estrutura

### "Não consigo conectar WordPress"
**Solução**: Certifique-se que o plugin REST API está ativo e a URL está correta (com https://)

### "Artigo muito genérico"
**Solução**: Use palavras-chave mais específicas e escolha o tipo de artigo adequado
